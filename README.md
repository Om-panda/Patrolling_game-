# 🎮 Patrolling Game (Unity 2D)

A simple and engaging 2D game built using Unity where the player moves within a defined area, collects stars, and tries to achieve the highest score.

---

## 🕹️ Gameplay
- Control the player using keyboard (W, A, S, D) or joystick (mobile)
- Move inside the playable camera area
- Collect stars to increase your score
- New stars spawn randomly after collection
- Continuous gameplay loop

---

## ✨ Features
- ⭐ Random star spawning system
- 🔁 Infinite gameplay loop
- 🎯 Score tracking system
- 🕹️ Supports both **PC and Mobile**
- ⚡ Smooth and optimized performance

---

## 🛠️ Tech Stack
- Unity Engine (2D)
- C#
- Unity UI System

---

## 🎯 Objective
Collect as many stars as possible and beat your highest score!
